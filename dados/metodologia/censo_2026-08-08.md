# Censo das Ações Penais do Plenário — 08/08/2026

Documento técnico. Registra o método, a consulta e os resultados do censo que substituiu a construção do universo por palavras-chave.

## 1. Acesso

A API pública do STF **não aceita acesso programático externo** — `curl` recebe `HTTP 202` com corpo vazio, com ou sem headers de navegador. Testado em 07/08/2026.

Funciona a partir do **contexto JavaScript da própria página** `jurisprudencia.stf.jus.br`, onde a sessão do navegador é válida:

```
POST /api/search/search
Content-Type: application/json
```

O endpoint aceita **query Elasticsearch crua**, incluindo agregações. Não há necessidade de scraping de DOM nem de download de CSV.

## 2. Schema do índice (59 campos)

Campos relevantes:

| Campo | Tipo | Uso |
|---|---|---|
| `base` | keyword direto | `"acordaos"` — filtra fora decisões monocráticas e súmulas |
| `processo_classe_processual_unificada_classe_sigla` | text (usar `.keyword`) | `"AP"` |
| `processo_classe_processual_unificada_incidente_sigla` | text | sufixo (`AgR`, `ED`, `EI`, `QO`…). **Ausente = AP pura** |
| `orgao_julgador` | text (usar `.keyword`) | `"Tribunal Pleno"` · `"Primeira Turma"` · `"Segunda Turma"` |
| `julgamento_data` | date | `AAAA-MM-DD` |
| `processo_numero` | numérico | |
| `relator_processo_nome`, `relator_acordao_nome` | | |
| `ementa_texto` | text | |
| `acordao_ata` | text | **fonte autoritativa de placar, unanimidade e vencidos** |
| `inteiro_teor_texto` | text | **texto integral indexado** |
| `partes_lista_texto` | text | nomes dos réus |
| `id` | keyword | `sjur{ID}` |

> `base` é keyword direto; `orgao_julgador` e `..._classe_sigla` exigem sufixo `.keyword`. Usar `term` no campo cru nesses dois retorna zero silenciosamente.

## 3. Consulta do censo

```javascript
const filtro = [
  {term: {base: "acordaos"}},
  {term: {"processo_classe_processual_unificada_classe_sigla.keyword": "AP"}},
  {term: {"orgao_julgador.keyword": "Tribunal Pleno"}},
  {range: {julgamento_data: {gte: "1991-01-01", lte: "2024-12-31"}}}
];

const query = {
  query: {bool: {
    filter: filtro,
    must_not: [{exists: {field: "processo_classe_processual_unificada_incidente_sigla"}}]
  }},
  size: 200,
  track_total_hits: true,
  _source: ["processo_numero","julgamento_data","relator_acordao_nome",
            "relator_processo_nome","id","ementa_texto"],
  sort: [{julgamento_data: "asc"}]
};

await fetch('/api/search/search', {
  method: 'POST',
  headers: {'Content-Type': 'application/json'},
  body: JSON.stringify(query)
});
```

Reprodutível em uma chamada. Sem paginação — o universo cabe em `size: 200`.

### 3.1 Limite de taxa — comportamento observado

O endpoint aplica limitação de taxa. Após aproximadamente oito consultas em sequência, passa a responder `HTTP 202` com corpo vazio — **inclusive a partir do contexto da própria página**, exatamente como responde a chamadas externas.

**Como restaurar:** recarregar a página (`jurisprudencia.stf.jus.br/pages/search`). O acesso volta imediatamente.

Consequências práticas para a execução:
- Planejar consultas em lotes pequenos, com recarga entre eles.
- Preferir uma consulta ampla com agregações a muitas consultas pontuais.
- **Sempre persistir o resultado em disco na hora.** Não depender de acesso ao vivo — não há compromisso de estabilidade nem documentação pública deste endpoint.

## 5. Achados

### 5.1 O vazio de 2015-2020 é institucional, não metodológico

O Plenário deixou de julgar ações penais no período; os processos de foro por prerrogativa migraram para as Turmas. Verificação pontual: a AP-996 (2018), a AP-694 (2017) e a AP-504 (2016) constam do índice como **Segunda ou Primeira Turma**.

Isso não é lacuna de coleta. É mudança no locus de julgamento — e portanto matéria substantiva para uma tese sobre estabilidade institucional. Ver `DECISOES.md` D-011.

### 5.2 Metade do universo é 8 de janeiro

**55 dos 105** casos são ações penais dos atos antidemocráticos de 8 de janeiro de 2023 — relator Alexandre de Moraes, ementas sobre propagação de ideias contrárias à ordem constitucional, acampamento em frente a quartel-general, dano qualificado. Explicam o pico de 41 casos em 2024.

### 5.3 Validação do banco existente

Os **26 casos coletados por palavra-chave estão todos presentes no censo**. O frame de coleta era válido; o problema era de cobertura e de precisão, não de enquadramento.

**Falsos positivos — 4 casos a remover** (`DECISOES.md` D-010):
`AP-1147` · `AP-1075` · `AP-1179` · `AP-2493` — todos do 8 de janeiro, capturados pela busca 17 (`(subtração ou inutilização) e (livro ou documento) e 337`) porque os réus destruíram bens e documentos públicos.

**Ausências — 2 casos a incluir:**

| AP | Julgamento | Relator | Tipo |
|---|---|---|---|
| AP-430 | 07/08/2008 | Cármen Lúcia | frustração dolosa do caráter competitivo de licitação |
| AP-527 | 16/12/2010 | Dias Toffoli | dispensa ou inexigibilidade de licitação fora das hipóteses legais (art. 89, Lei 8.666/93) |

**Excluída após análise:** `AP-481` (2011) — corrupção eleitoral do art. 299 do Código Eleitoral, fora das 19 modalidades de Levcovitz.

### 5.4 Universo final

```
26 coletados − 4 contaminados + 2 ausentes = ~24 casos de corrupção
```

O n é pequeno e agora está medido. Confirma a orientação de não perseguir modelo econométrico (`DECISOES.md` D-006).
